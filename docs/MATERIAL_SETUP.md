# 材料与模拟条件配置

自然语言任务先确定材料结构、研究条件和目标性质。Codex结合这些信息选择已登记的构建、模拟、分析和校验工具；各工具保存自己的输入、参数和实际产物。

## 给Codex哪些信息

一项可执行的聚合物任务通常需要：

- 材料名称、重复单元或完整链结构，以及需要区分的端基和立构信息。
- 聚合度、链数；共聚物另给组成与序列要求。
- 温度、压力、材料状态和目标性质。
- 计算服务器、可用软件、计算预算与本次停止阶段。
- 已有结构、拓扑、轨迹或参考数据的路径。

结构尚未确定时，规划模型可以先阅读相关资料、提出候选并保存来源。结构校验通过后，再选择对应的构建与计算步骤。材料名称无法唯一确定结构时，先补齐需要区分的结构信息。

一个用于输入校验的任务示例：

> 检查聚氧化乙烯重复单元`*CCO*`，每条链10个重复单元，共12条链。先选择已登记的构建方法和力场，记录结构与参数检查结果，完成校验1后停止。

这里的`*`表示重复单元连接点。输入校验和参数化检查分别确认结构与工具的可用性。

## 已登记的结构表示

运行`list_polymer_preparation_capabilities`查看当前安装的能力。原通用输入校验器和EMC构建登记支持以下表示：

| 适配器 | 主要结构输入 |
| --- | --- |
| `pe_lcb` | 聚乙烯支化点、支链长度、放置方式和碳数预算 |
| `linear_alpha_olefin` | 线性α烯烃的侧链长度和链长要求 |
| `linear_homopolymer` | `repeat_unit_smiles`、重复单元碳数及每链重复单元数 |
| `explicit_polymer_chain` | `polymer_smiles`，表示一条完整、连通且已封端的分子链 |
| `templated_polymer_chain` | `repeat_unit_templates`和`sequence`，可附加支链模板与规则 |

模板序列支持均聚、周期、交替、嵌段和随机表示。环状、星形、交联等结构按相应的登记构建能力处理。各适配器的实际必填项和检查结果由工具返回。

当前登记的力场为OPLS-AA。通用构建能力涉及C、H、N、O、P、S、F、Cl、Br和I；具体原子类型和键参数还要经过EMC构建及GROMACS `grompp`检查。需要其他力场或元素时，接入其参数文件、构建适配器和相应校验记录。

## 选择模拟与分析配置

现有聚乙烯熔体示例使用GROMACS 2024.4、150条链、400 K和1 atm，并保留原四阶段参数。目前生产worker读取这套固定MDP。其他材料、温压或时长先登记并选择对应的模拟适配器与MDP，运行记录保存各阶段输入哈希和实际条件。

分析配置还需要明确原子选区、分子链映射、端点和主链。现有聚乙烯分析包含C–C RDF与碳骨架上的链内距离。含O/N等主链原子的材料需要相应的真实键图与选区映射；环状、星形和交联体系需要适合其拓扑的观测量。

现有分析工具覆盖密度、回转半径、末端距、MSD/扩散、RDF、形状、接触与松弛等量。玻璃化温度、力学或电学任务先登记对应的计算协议及校验依据。

## 配置科学规则与结果状态

`list_supported_rule_properties`和`get_rule_profile`用于查看已有性质与规则。通用规则资源支持从登记的结构化参考数据提出规则，并检查材料、条件、力场和方法的适用性。

参考数据充分且符合登记要求时，原规则工具可以生成并激活相应规则。缺少匹配规则或独立依据的结果保存为WARN/REVIEW。计算记录继续保留数值、单位、采样条件、来源和需要补充的项目。

任务通过相同规则再次校验后归档。计算完成情况和科学验收情况分别记录。
