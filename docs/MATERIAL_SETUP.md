# 材料与模拟条件配置

用户说明材料、结构和研究条件，Codex据此选择构建、模拟、分析和校验工具。默认结果为密度、Rg、Ree、链形状、RDF和MSD。

## 准备材料信息

- 材料名称、重复单元或完整链结构，以及端基和立构信息。
- 聚合度、链数；共聚物另给组成和序列要求。
- 温度、压力、材料状态与目标性质。
- 服务器、计算预算和本次停止阶段。
- 已有结构、拓扑、轨迹或参考数据的路径。

结构尚未确定时，可以先让Codex查阅资料并提出候选。示例：

> 检查聚氧化乙烯重复单元`*CCO*`，每条链10个重复单元，共12条链。请选择构建方法和力场，完成输入校验后停止。

`*`表示重复单元的连接点。结构检查通过后，工具继续检查原子类型和力场参数。

## 选择结构表示

用`list_polymer_preparation_capabilities`查看当前安装的能力。

| 适配器 | 结构输入 |
| --- | --- |
| `pe_lcb` | 聚乙烯支化点、支链长度、支化位置和碳数 |
| `linear_alpha_olefin` | 线性α烯烃侧链长度和链长 |
| `linear_homopolymer` | `repeat_unit_smiles`、重复单元碳数及重复单元数 |
| `explicit_polymer_chain` | 完整、连通且已封端的`polymer_smiles` |
| `templated_polymer_chain` | `repeat_unit_templates`和`sequence`，可补充支链模板 |

模板序列支持均聚、周期、交替、嵌段和随机排列。环状、星形及交联结构需要对应的构建方法。

当前提供OPLS-AA。构建器可处理C、H、N、O、P、S、F、Cl、Br和I；具体原子类型及键参数通过EMC构建和GROMACS `grompp`检查。其他力场和元素需配置相应参数及构建工具。

## 配置模拟和分析

预置聚乙烯示例使用GROMACS 2024.4、150条链、400 K、1 atm及四阶段模拟条件。其他材料或条件需配置对应的模拟方法与MDP文件。

分析需要明确原子选区、分子链、主链和端点。聚乙烯示例使用C–C RDF和碳骨架链内距离。含O、N等主链原子的材料需配置真实键连接及选区映射；环状、星形和交联结构选择适合其拓扑的观测量。

玻璃化温度、力学或电学计算需要额外的计算方法和校验依据。

## 配置结果校验

用`list_supported_rule_properties`和`get_rule_profile`查看现有性质与规则。新材料的参考数据应与组成、温度、力场和计算方法相符。

参考依据齐全时，工具按对应规则检查结果。需要补充依据或处理的问题分别记录为WARN/REVIEW。每个案例保存计算完成情况、校验状态、数值、单位、采样条件和来源；处理后再次校验并归档。
